# fundraising

Минималистичный Telegram-бот (aiogram 3 + SQLite) для общих сборов в чате квартирантов.
Языки: русский и узбекский. Валюты: сум и доллар. Всё управление — inline-кнопками, команда одна: `/menu`.

В группе видно только общее: меню, список сборов, жильцы и карточки сборов.
Всё личное — создание сбора, карта, долги, «✅ Я оплатил» с чеком — открывается в личке с ботом.

## Два типа сборов

**💰 Поделить сумму.** Один оплатил (например, коммуналку 300 000 сум), сумма делится на участников:
по 50 000 сум с каждого из шести. В карточке видна карта получателя (Uzcard / Humo).

**🔁 По очереди.** Каждый раз платит следующий по списку (например, свет по 100 000 сум):

```
1. ✅ Абду
2. 👉 Али ← сейчас
3. ⏳ Вали
```

Любой платёж закрывает текущий ход. Если вместо Али заплатил Вали, ход закрыт,
а Али в следующем круге должен заплатить два раза (`×2`).

## Как пользоваться

1. Добавьте бота в группу и напишите `/menu`.
2. Каждый жилец один раз нажимает **🙋 Я в доле**.
3. **💳 Моя карта** — откроется личка: отправьте `8600 1234 5678 9012 Имя Фамилия` (`-` — удалить).
4. **➕ Новый сбор** — откроется личка: выберите тип и отправьте сумму с названием:
   `300000 Коммуналка`, `300 000 сум Газ`, `300k Свет`, `300 ming Kommunal`, `50$ Интернет`.
   Без валюты — сумы.
5. В черновике отметьте участников (для очереди — нажимайте по порядку), при желании
   смените валюту и нажмите **✅ Создать** — карточка появится в группе.
6. Под карточкой **✅ Я оплатил** открывает личку: бот просит фото чека и пересылает его автору сбора
   с кнопками **✅ Подтвердить** / **❌ Отклонить**. Отметка в группе ставится после подтверждения
   (пока чек проверяется — 🕓).
7. Автор сбора может **🔔 Напомнить** должникам и **🔒 Закрыть** сбор.
   Когда все оплатили «поделить сумму», сбор закрывается сам.

Доля округляется вверх: сумы — до 100 сум, доллары — до цента.

## Настройка

`.env`:

```
BOT_TOKEN=токен от @BotFather
ADMIN_CHAT_ID=ваш Telegram ID (узнать у @userinfobot)
DB_PATH=data/bot.db
```

Язык один на весь бот, и менять его может только `ADMIN_CHAT_ID`: `/menu` в личке с ботом → **🌐 Язык**.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/python main.py
```

База создаётся сама в `data/bot.db`; база от прошлых версий обновляется при запуске.

### На сервере (systemd)

Скопируйте проект в `/opt/fundraising`, создайте там `.venv` и `.env`, затем:

```bash
sudo cp fundraising-bot.service /etc/systemd/system/
sudo systemctl enable --now fundraising-bot
```
