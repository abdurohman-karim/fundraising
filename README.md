# fundraising

Минималистичный Telegram-бот (aiogram 3 + SQLite) для общих сборов в чате квартирантов.
Один человек оплатил (коммуналку, интернет…), бот делит сумму на участников
и показывает его карту Uzcard / Humo. Каждый переводит свою долю и жмёт «✅ Я оплатил».

Языки: русский и узбекский (выбирается для каждого чата). Валюты: сум и доллар.
Всё управление — inline-кнопками, команда нужна одна: `/menu`.

## Как пользоваться

1. Добавьте бота в группу и выберите язык.
2. Меню (`/menu`) — кнопки:
   - **🙋 Я в доле** — войти в список жильцов (каждый жмёт один раз);
   - **💳 Моя карта** — ответьте на сообщение бота номером: `8600 1234 5678 9012 Имя Фамилия`
     (`-` — удалить). Карту можно сохранить и в личке с ботом;
   - **➕ Новый сбор** — ответьте на сообщение бота суммой и названием:
     `300000 Коммуналка`, `300 000 сум Газ`, `300k Свет`, `300 ming Kommunal`, `50$ Интернет`, `50 usd Интернет`.
     Без валюты — сумы;
   - **📋 Открытые сборы** — список; нажатие переносит карточку сбора вниз чата;
   - **🧾 Мои долги**, **👥 Жильцы**, **🌐 Язык**.
3. Бот присылает черновик: галочками отметьте, кто участвует в этот раз,
   при необходимости переключите валюту и нажмите **✅ Создать**.
4. Под сбором кнопки: **✅ Я оплатил** (поставить / снять отметку), **🔔 Напомнить** (тегает должников)
   и **🔒 Закрыть** — последние две только для автора. Когда все оплатили, сбор закрывается сам.

Доля округляется вверх: сумы — до 100 сум, доллары — до цента.
Пример: 300 000 сум на 6 человек → по 50 000 сум.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
.venv/bin/python main.py
```

База создаётся сама в `data/bot.db`.

### На сервере (systemd)

Скопируйте проект в `/opt/fundraising`, создайте там `.venv` и `.env`, затем:

```bash
sudo cp fundraising-bot.service /etc/systemd/system/
sudo systemctl enable --now fundraising-bot
```
