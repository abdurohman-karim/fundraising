# fundraising

Минималистичный Telegram-бот (aiogram 3 + SQLite) для общих сборов в чате квартирантов.
Один человек оплатил (коммуналку, интернет…), бот делит сумму на всех жильцов из списка
и показывает его карту Uzcard / Humo. Каждый переводит свою долю и жмёт «✅ Я оплатил».

## Как пользоваться

1. Добавьте бота в группу.
2. Каждый жилец один раз нажимает «🙋 Я в доле» (кнопка под `/start`) или пишет `/join`.
3. Тот, кто платит, сохраняет карту (один раз, можно в личке боту):
   `/card 8600 1234 5678 9012 Имя Фамилия`
4. Создаёт сбор:
   - `/new 300000 Коммуналка`
   - `/new 300 000 сум Газ` · `/new 300k Свет`
   - `/new 50$ Интернет` · `/new 50 usd Интернет`

   Без валюты — сумы. Доля округляется вверх: сумы — до 100 сум, доллары — до цента.
   Пример: 300 000 сум на 6 человек → по 50 000 сум.
5. Под сообщением сбора кнопки:
   - **✅ Я оплатил** — отметить/снять свою оплату;
   - **🔔 Напомнить** — автор сбора тегает всех, кто ещё не оплатил;
   - **🔒 Закрыть** — автор закрывает сбор. Когда все оплатили, сбор закрывается сам.

Другие команды: `/list` — открытые сборы, `/debts` — мои долги (в личке — по всем чатам),
`/members` — кто в списке, `/leave` — выйти из списка, `/card` — показать карту, `/card -` — удалить.

Участники сбора фиксируются в момент создания: кто войдёт в список позже, попадёт только в следующие сборы.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
.venv/bin/python main.py
```

База создаётся сама в `data/bot.db`.

### На сервере (systemd)

Скопируйте проект в `/opt/fundraising`, создайте там `.venv` и `.env`, затем:

```bash
sudo cp fundraising-bot.service /etc/systemd/system/
sudo systemctl enable --now fundraising-bot
```
